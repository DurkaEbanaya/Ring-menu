# Скриншоты 0.15

Сгенерированы `ExplorerRing-v015.exe --screenshots` из настоящего WinForms-интерфейса в Windows 10, с помощью `DrawToBitmap`. На снимках только приложение и синтетический фон предпросмотра; никаких личных файлов, окон и рабочего стола.

- `settings-gestures.png` — настраиваемые пороги и задержки.
- `settings-appearance.png` — Acrylic/прозрачность/Reveal/текстура, пример включённого материала.
- `settings-background.png` — справка о трее и кнопка автозапуска; автозапуск выключен.
- `settings-solid.png` — пример отключённого Acrylic, Reveal 35%.

Preview использует настоящий renderer кольца, но **имитацию размытия синтетического фона**, не захват DWM. Поэтому изображения не являются доказательством качества Acrylic на физическом экране. Настоящее кольцо с DWM доступно отдельной кнопкой и не выполняет файловые команды в режиме примера.
